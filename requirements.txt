# =============================================================
#  Smart Commute Frontend — requirements.txt
#  Install: pip install -r requirements.txt
#
#  The frontend needs NO pip packages. Everything below is a
#  comment so this command runs cleanly (it installs nothing).
#  The Flutter packages are installed with `flutter pub get`.
# =============================================================

# ── STEP 0: FIND YOUR IP ADDRESS ──────────────────────────────
# The addresses below depend on the PC running the backend.
# Find its IP (Wi-Fi / LAN) in PowerShell:
#   ipconfig
#   -> look for "IPv4 Address" under your Wi-Fi adapter,
#      e.g. 192.168.1.6
#
# Everywhere below, replace <YOUR_IP> with that address.
#   - Same PC only?           you can use localhost instead
#   - Phone / other laptop?   must use <YOUR_IP>, and be on
#                             the same Wi-Fi network
#
# The IP can change when you reconnect to Wi-Fi or switch
# networks — check ipconfig again and update .env if it does.
#
# If other devices can't connect, allow Python / Dart through
# Windows Defender Firewall (Private networks).

# ── STEP 1: BACKEND (Smart-Commute-Backend) ───────────────────
# Must be running first:
#   .\venv\Scripts\activate
#   uvicorn app.main:app --reload --host 0.0.0.0 --port 8000
#
# Port 8000 belongs to the backend — don't use it for the
# website or the app.
#
# The backend only accepts requests from addresses listed in
# ALLOWED_ORIGINS (Smart-Commute-Backend/.env). Add these, then
# restart the backend:
#   http://localhost:5000,http://<YOUR_IP>:5000   (Flutter app)
#   http://localhost:5500,http://<YOUR_IP>:5500   (website)

# ── STEP 2: WEBSITE (web_portal/) ─────────────────────────────
# Uses only Python's built-in http.server — nothing to install.
# Requires: Python 3.x
#
#   cd web_portal
#   python -m http.server 5500 --bind 0.0.0.0
#   then open http://<YOUR_IP>:5500   (or http://localhost:5500)

# ── STEP 3: APP (Flutter) ─────────────────────────────────────
# Requires: Flutter SDK >= 3.44.8 (stable), Dart >= 3.3.0 < 4.0.0
# Needs a .env file in smartcommute_frontend/ (listed as an asset):
#   API_BASE_URL=http://<YOUR_IP>:8000
#   WS_BASE_URL=ws://<YOUR_IP>:8000
#   DEBUG_LOGGING=true
#
# Run from inside smartcommute_frontend/:
#   flutter pub get
#   flutter run -d web-server --web-hostname 0.0.0.0 --web-port 5000
#   wait for "is being served at ...:5000",
#   then open http://<YOUR_IP>:5000 in Chrome yourself
#
# After changing .env, stop the app (q) and run it again —
# hot reload does not pick up .env changes.
#
# Note: "Center on my location" only works on
# http://localhost:5000 or over https. Browsers block GPS on
# plain http://<YOUR_IP> addresses.
#
# Note: `flutter run -d chrome` (and -d edge) fails on some PCs
# with "Failed to launch browser after 3 tries" — use the
# web-server command above instead. Hot reload still works:
# press r in the terminal, then refresh the page.
#
# Packages (from pubspec.yaml, versions locked in pubspec.lock):
